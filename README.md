# Employee Management System - Backend

This repository contains the backend implementation of the **Employee Management System**, developed using **Java**, **Spring Boot**, and **MySQL**. It exposes RESTful APIs for managing employee records and serves as the backend service for the React.js frontend.

---

## 📌 Features

- Employee CRUD Operations
- RESTful API Development
- Spring Boot Framework
- Spring Data JPA Integration
- MySQL Database Connectivity
- Exception Handling
- Input Validation
- Layered Architecture

## 🚀 Getting Started

### Prerequisites

- Java 17+
- Maven
- MySQL

### Installation

```bash
git clone https://github.com/ramakrishnagollavelli23/employee_backend.git

cd employee_backend

mvn spring-boot:run
```
